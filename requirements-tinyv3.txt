#
# Hard requirements specific to tinyv3:
#   * fla-core (KDA linear-attention kernels, imported as `fla`). There is no
#     eager fallback: without it the model raises a clear ImportError at
#     load time. Do NOT install fla-core[cuda] into an existing torch env
#     blindly — resolve any torch/triton upgrade prompts before installing.
#   * triton==3.8.0: required by the KDA kernels; also note that triton 3.8
#     breaks torch 2.5 inductor compilation, so this codebase intentionally
#     runs the vendored vision RoPE helper eagerly (see the NOTE in
#     modeling_bailing_moe_v3_vl.py).
#   * flash-attn>=2.6: the qwen3_moe_vit vision tower uses attention logit
#     soft-capping; older flash-attn builds (e.g. 2.3.x) do not support it.
#     The public CLI defaults tinyv3 to --attn-implementation sdpa; vision
#     softcap support is a load-time requirement of the vision tower.
